## 🌟 نظرة عامة | Overview

**Chapter 1 Exam Arena** هي منصة تعليمية وتقييمية متطورة تم بناؤها خصيصاً لطلاب مرحلة البكالوريا والثانوية العامة لدراسة ومراجعة **الفصل الأول من منهج الذكاء الاصطناعي**. 

تم تصميم المنصة بأعلى معايير الأمان ونزاهة الاختبارات (**Anti-Cheat Integrity**) مع تجربة ألعاب غامرة (**Gamified Experience**) لمنع حفظ الإجابات أو تكرارها، وضمان استحالة استخراج الإجابات المكشوفة من كود الواجهة أو الذاكرة.

## 🛡️ بنية الأمان ومكافحة الغش | Security & Anti-Cheat Architecture

تم تطبيق منظومة أمان متكاملة تلبي أعلى متطلبات النزاهة الأكاديمية:

1. **تشفير الإجابات الصفرية (Zero Plaintext Answers)**:
   - لا توجد أي إجابة صحيحة مخزنة كنص مكشوف أو رقم فهرس داخل كود الجافاسكريبت أو عناصر الصفحة (DOM).
   - يتم التحقق من صحة الإجابة لحظياً باستخدام خوارزمية التشفير القياسية **SHA-256** مع ملح أمان مخصص لكل سؤال (`Per-Question Salted Hash`).
2. **تشفير الشروحات التفسيرية (Encrypted Explanations)**:
   - نصوص الشروحات مشفرة تماماً عبر مجرى تشفير XOR ثنائي المفتاح مشتق من بصمة الإجابة الصحيحة. لا يمكن فك تشفير الشرح أو قراءته قبل تأكيد واختيار الإجابة الصحيحة.
3. **حماية التفتيش وفحص الشفرة (Anti-Inspect & DevTools Defense)**:
   - تعطيل قائمة النقر بزر الفأرة الأيمن (Context Menu) مع إشعار تحذيري فوري.
   - حظر اختصارات لوحة المفاتيح الخاصة بأدوات المطورين (`F12`, `Ctrl+Shift+I`, `Ctrl+Shift+J`, `Ctrl+Shift+C`, `Ctrl+U`, `Ctrl+S`).
   - حظر نسخ وتحديد نصوص الأسئلة (`No-Copy Protection`) لمنع تداول الأسئلة عبر روبوتات الذكاء الاصطناعي أثناء الاختبار.
4. **رصد مغادرة نافذة الاختبار (Tab-Switch & Blur Tracking)**:
   - نظام رصد نشط يكتشف مغادرة التبويب أو تصغير النافذة ويسجل عدد المخالفات لتحذير الطالب.
5. **عزل حالة الاختبار (Enclosed Execution State)**:
   - تم تغليف محرك الاختبار بالكامل داخل دالة ذاتية الاستدعاء معزولة (`IIFE Module`) مع تجميد الكائنات لمنع التلاعب بنقاط `score` أو المحاولات `lives` عبر نافذة الأوامر (`Console`).

## 🔄 منع تكرار الأسئلة والخيارات | Anti-Duplication Engine

- **فرز عشوائي بدون إحلال (Fisher-Yates Shuffle)**: في كل جولة اختبار، يتم سحب الأسئلة دون أي تكرار للسؤال داخل نفس الجلسة.
- **تتبع الجلسة وسجل الأسئلة المشاهدة (`Session Pool Tracker`)**: تحفظ المنصة معرفات الأسئلة التي تمت الإجابة عليها في الجلسة، لتعطي الأولوية للأسئلة الجديدة في الجولات التالية حتى استنفاد كامل بنك الأسئلة.
- **عشوائية مواقع الخيارات**: يتم خلط ترتيب الخيارات (A, B, C, D) لكل سؤال في كل مرة يظهر فيها، مما يجعل حفظ مواقع الإجابات مستحيلاً.
- **استقلالية التوصيل والترتيب**: يتم خلط عناصر المفاهيم والتعريفات، وكذلك عناصر الترتيب الهرمي بشكل منفصل تماماً مع ضمان عدم ظهور الترتيب محلولاً مسبقاً.

## 🎨 واجهة وتجربة المستخدم | Design & Aesthetics

- **تصميم زجاجي سايبراني (Cyber-Academic Glassmorphism)**: خلفيات داكنة عميقة بتدرجات راديال ناعمة، وبطاقات شفافة بفلتر ضبابي (`backdrop-filter: blur(18px)`) وحدود نيون متوهجة.
- **تأثيرات صوتية تفاعلية مدمجة (Web Audio API Synthesizer)**:
  - أصوات نقرات ناعمة، رنين موسيقي ثلاثي النغمات للإجابة الصحيحة، طنين تنبيهي للإجابة الخاطئة، وموسيقى فوز ختامية، وكل ذلك **بدون أي ملفات صوتية خارجية**، مع إمكانية كتم الصوت بضغطة زر.
- **شريط علوي مباشر (Real-Time HUD)**:
  - قلوب المحاولات (3 أرواح مع حركة نبض واهتزاز عند الخطأ).
  - مستويات الخبرة (من رتبة مستكشف مبتدئ حتى خبير الذكاء الاصطناعي الأكبر).
  - عداد النقاط ومضاعف السلاسل المتتالية (`Streaks`).
  - أرقام طافية متحركة (`+15 XP` / `-7 XP`) تصعد وتتلاشى فورياً.
- **تحليل النتائج بعد الاختبار**:
  - عرض النسبة المئوية للدقة، والنتيجة النهائية، وأطول سلسلة.
  - **مخطط تفصيلي لمستوى الإتقان حسب كل درس من دروس الفصل الأول** (Lesson 1-1 إلى 1-4).

## 🎯 أنماط الاختبار | Assessment Modes

1. ⚡ **التحدي الشامل (Mixed Gauntlet)**: يجمع كل أنماط الأسئلة بشكل ديناميكي (اختيار، توصيل، ترتيب، صح وخطأ).
2. 📝 **بنك الاختيار من متعدد (MCQ Arena)**: أسئلة اختيار دقيقة تغطي المفاهيم الفنية والتعريفات.
3. 🔗 **تحديات التوصيل والربط (Match & Connect)**: مصفوفة توصيل تفاعلية لربط المصطلحات بتعريفاتها.
4. 📶 **ترتيب الهرمية ومسارات التدفق (Hierarchy & Flow Sorter)**: ترتيب طبقات الشبكات العصبية، هرمية الذكاء الاصطناعي، والتسلسل التاريخي.
5. ⏱️ **تحدي السرعة الخارق (Speedrun Arena)**: مؤقت زمني حاسم (45 ثانية لكل سؤال) يتطلب تركيزاً وسرعة استجابة فائقة.

## 📚 محتوى ومحاور الفصل الأول | Syllabus Coverage

- **الدرس 1-1 (عتاد الحوسبة والحدود الفيزيائية)**:
  - تطور الحواسيب من الصمامات المفرغة (ENIAC) إلى الترانزستور والشرائح المتكاملة.
  - قانون مور (Moore's Law) وتضاعف كثافة الترانزستورات كل سنتين.
  - القيود النانوية: تيار التسرب (Leakage Current) والنفق الكمي (Quantum Tunneling).
  - الحوسبة الطرفية (Edge Computing) وأهميتها لتقليل زمن التأخير (Latency).
  - طبيعة الحوسبة الكمية (Quantum Computing) ومجالاتها المتخصصة.
- **الدرس 1-2 (أسس الشبكات العصبية وتصنيف الذكاء الاصطناعي)**:
  - الهرمية المتداخلة: AI > Machine Learning > Deep Learning > Generative AI.
  - مكونات الخلية العصبية الاصطناعية: الأوزان المشبكية (Weights)، الانحياز (Bias)، المجموع الموزون.
  - دوال التنشيط (Activation Functions) وأهمية اللاخطية (Non-linearity).
  - بنية الطبقات: طبقة الإدخال، الطبقات المخفية (استخراج الميزات الهرمية)، وطبقة الإخراج.
- **الدرس 1-3 (نظم التوصية والذكاء الاصطناعي في الصناعة)**:
  - التصفية التعاونية (Collaborative Filtering) والتصفية المعتمدة على المحتوى (Content-Based).
  - قياس تشابه جيب التمام (Cosine Similarity) في الفضاء المتجهي.
  - مشكلة البداية الباردة (Cold Start Problem).
  - الصيانة التنبؤية (Predictive Maintenance) ومقياس العمر المفيد المتبقي (RUL).
- **الدرس 1-4 (حوكمة وأخلاقيات الذكاء الاصطناعي)**:
  - المبادئ الأربعة: العدالة (Fairness)، الشفافية (Transparency)، الخصوصية (Privacy)، والمساءلة (Accountability).
  - معضلة الصندوق الأسود وأدوات الذكاء الاصطناعي القابل للتفسير (XAI / LIME / SHAP).
  - المتغيرات البديلة (Proxy Variables) وتسلل التحيز الخوارزمي.
  - ظاهرة هلوسة النماذج التوليدية (AI Hallucination) وأهمية التحقق النقدي البشري.
  - الفرق الجوهري بين المسؤولية الفنية للمطورين (Responsibility) والمساءلة القانونية للمؤسسات (Accountability).

## 🚀 كيفية التشغيل محلياً | How to Run Locally

لا تتطلب المنصة أي تثبيت معقد؛ إنها تطبيق ويب متكامل وخفيف:

1. قم بتحميل أو استنساخ المستودع:
   \`\`\`bash
   git clone https://github.com/abdelrahmaans/Bakaloria-Chapter-1.git
   cd Bakaloria-Chapter-1
   \`\`\`
2. افتح ملف \`index.html\` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox, Safari) أو شغله عبر أي خادم ويب محلي:
   \`\`\`bash
   # باستخدام Python
   python -m http.server 3000
   # أو باستخدام Node.js
   npx serve .
   \`\`\`
3. استمتع بتجربة التقييم الآمنة!
